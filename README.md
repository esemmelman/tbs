# My Links

A responsive, centered menu for websites and calendars. Choose a category, then choose a destination to open its URL in the current tab. Use Main to return to the starting menu or Back to return to the previous screen.

No dependencies or build step. Open `index.html` in a browser. Links and categories are defined in `app.js`.

Published at https://esemmelman.github.io/tbs/.

The current revision is displayed at the top-left of every menu. When publishing changes, increment the revision in `index.html` and use the same number in both asset query strings to refresh cached CSS and JavaScript.
